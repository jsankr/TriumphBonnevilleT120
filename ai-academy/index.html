Mental model

How does ChatGPT answer?

① Your words become tokensThe prompt is divided into chunks the model can process.
② Tokens become numbersEmbeddings and learned transformations represent relationships and context.
③ The model estimates what comes nextBillions of learned numerical weights shape predictions; GPUs speed the math.
④ The system builds a responseIt generates tokens step by step. Connected tools may retrieve fresh information; generated answers still need checking.

Analogy: an LLM is not a searchable filing cabinet. It is more like an exceptionally powerful pattern learner that constructs responses — and sometimes makes mistakes. It has no guaranteed truth detector.

Your agent workshop

Build nine helpful assistants

Agent building recipe

Define a goal → list trusted inputs → write instructions → choose tools → require approval before outside actions → test normal and malicious examples → measure accuracy and time saved. A prompt-only prototype is not an automatically running agent until you connect a reliable trigger and tools.

Final capstone

From “I have an idea” to “It's live!”

1 · Describe“Build a responsive website about my hobby with searchable cards, accessibility and saved preferences.”
2 · Preview & testInspect desktop and mobile layouts, keyboard navigation, links and browser errors. Never trust generated code without checking.
3 · PublishCreate a public GitHub repository; add index.html; Settings → Pages → Deploy from a branch → main / (root).
4 · VerifyOpen your published github.io URL in a private browser window, test each feature, and repeat after changes.

Security reminder: GitHub Pages serves public static files. Never store passwords, tokens, private keys or sensitive personal data in the website source. Use a real backend for authentication, protected data and API secrets.

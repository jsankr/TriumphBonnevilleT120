# Private fitment and real-photo teardown guidance

This project covers the **2018 liquid-cooled Triumph Bonneville T120**. It is an independent enthusiast reference and not an authenticated VIN-specific electronic parts catalogue.

## Confidential vehicle information

- Never commit a complete VIN, registration number, registration photo, personal identifiers or private garage data to GitHub Pages or this public repository.
- Browser code, comments, filenames, screenshots, URLs, analytics and client-side storage must not include confidential VINs.
- For a confidential VIN-based parts lookup, use a trusted dealer/manufacturer system or a separately secured server-side service. The static public application cannot securely retain VINs.
- Do not log exact VINs. Only record non-identifying fitment findings (market/model-year, document edition, component group and verification state) in public code.
- The existence of a VIN-specific parts branch does not prove a part fits a modified motorcycle without checking the supplier and installed configuration.

## Photo and teardown evidence

- Use your own permission-cleared photographs with registration plates, identifiers and sensitive EXIF metadata removed.
- Capture left/right full views, front/rear three-quarter, wheel and brakes, forks and rear shocks, engine sides and cockpit.
- Distinguish **stock Triumph components** from aftermarket modifications such as Kineo wheels and TEC progressive fork springs.
- A single assembled motorcycle photograph cannot reveal hidden fastener position, internal part geometry or correct disassembly order.
- For exploded views, use verified 2018 T120 manufacturer/authorized-dealer parts diagrams with properly licensed display rights, or authentic step-by-step disassembly photographs of the actual parts. Do not invent extra shocks, forks or calipers.

## Workshop-data requirements

- Map each visible spare to a stable ID, side, quantity, OEM candidate, applicable market/VIN range where known, source page, tool type, tool/bit size and each relevant fastener torque.
- Preserve evidence status and original edition. A value from April 2016 T120 service documentation is a **2016 reference**, not proof of applicability to an individual 2018 India-market motorcycle.
- Earlier Bonneville/T100 (2012/2006) data must never be represented as 2018 T120 manufacturer specifications.
- Unknown and conflicting tool sizes, fastener torques, part numbers, tightening sequences, or fitment must remain visibly **NOT VERIFIED**.
- Never publish copyrighted manuals or OEM diagrams without permission. The app offers private local PDF viewing and links to providers that may restrict access.

## External supplier links

Some third-party OEM-parts catalogue hosts deny access by country, session, or anti-bot filtering. In-app indexed callouts and source references must stay operational when all external sites fail. The source alternatives in the explorer are **model-level catalogue landing pages**, not guaranteed assembly drawing links. See [link audit](LINK-AUDIT.md).

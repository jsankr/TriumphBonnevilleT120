# 2018 T120 OEM exploded-view evidence audit

## Scope
This project links eight **2018 Bonneville T120** OEM-model parts fiches, retains the original numbered callout identifiers and lists 171 catalogue part-number entries including alternatives. This is a **curated subset**, not a complete bill of materials. Callout clusters spread apart when users move the separation slider, but they are navigation cards, **not mechanically measured 3D models**. The actual external exploded drawing is accessible through the associated source URL. No third-party OEM illustrations or copyrighted service-manual pages are reproduced.

The manual's printed p.70 is anomalously titled Front Brakes while containing Engine Covers entries; its rows remain **quarantined** from front-brake torque claims.

## Strict limitations
- A part catalogue's M6/M8/M10 bolt **thread size is not a socket, Allen, Torx or wrench-drive size**; exact drive size remains unknown unless sourced.
- 2018 VIN/market, part supersession, after-market Kineo wheels and TEC fork springs remain unconfirmed and should be verified privately by a dealer or manufacturer.
- Different-production or bulk-pack alternatives sharing an original callout are grouped, **never treated as extra installed components**.
- No personal VIN is collected, retained, transmitted or embedded in this static application.
- Forum reports cannot be used as manufacturer torque evidence.
- Screen-reader and Chrome/Chromium desktop, tablet and mobile checks are development requirements; Firefox and Safari physical-device verification remains open.

# T120 Workshop Explorer — Codex and developer operating rules

- Target **2018 Triumph Bonneville T120**. Factory MY18 brake equipment: Nissin, not later-year Brembo. Two front fork legs, two rear shocks.
- Source-fidelity first: do not invent torque values, tool/bit sizes, OEM parts, prices, fitment, VIN applicability, service steps or citations.
- 2016 T120 service and owner documents are 2016 references, **not certified for every 2018 India-market VIN**.
- `data/source-reference.json` is the curated factual database: 230 active torque references, 13 quarantined page-70 records, 44 maintenance tasks, 37 service tools, 32 owner specifications.
- `manual-page-index.json` is a **navigation-only** index of 894 source pages. Never infer tool or repair values from page topic snippets.
- 2012 and 2006 earlier-model documents must never supply 2018 T120 service values.
- Do not publish the copyrighted PDF manuals or their complete textual/page-image reproductions. Users open originals locally in their browsers.
- The user-supplied motorcycle concept illustration is not an OEM photograph or dimensional 3D model. The deterministic evidence assistant is not a live AI model.
- Before publishing, run the Node syntax/data/index tests; confirm source page anchors and mobile controls. Keep GitHub Pages deployment status separate from Git commit status.
